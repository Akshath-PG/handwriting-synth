Phase 1: Basic understanding of vanilla GCN
GCN (Graph Convolutional Network): a neural network that works directly on graph-
structured, non-Euclidean data G(V, E). Every layer updates each vertex's feature vector
using the vertex itself and its neighbours, with one weight matrix W shared by all vertices.

Vanilla GCN: the original form (Kipf and Welling, 2017): add self-loops, normalize the
adjacency symmetrically by degree, multiply by W, apply ReLU. No attention, no
neighbour sampling.

     Input: adjacency matrix A ∈ {0, 1}^(N×N), N = |V| (number of vertices); feature matrix
     H(0) ∈ R^(N×F), one row per vertex.
     Layer l: H(l) ∈ R^(N×F) → H(l+1). After L layers a vertex has seen everything within L
     hops.
     Graph embedding: add up all rows of H(L) into one vector h_G. Two graphs are
     compared through their h_G.

Idea in one line: each layer is one round of "ask your neighbours, average their answers
with yours, then re-weight".


Isomorphic graphs
G1 ≅ G2 (G1 is isomorphic to G2) when there is a bijection φ : V1 → V2 with (u, v) ∈ E1 ⇔
(φ(u), φ(v)) ∈ E2. In matrix form A2 = P A1 Pᵀ, with P a permutation matrix. The two graphs
are the same structure with the vertices renamed.

Example: G1 has edges {0–1, 0–2, 1–2, 2–3}. With φ = (0→2, 1→3, 2→0, 3→1), G2 has edges {2–
3, 2–0, 3–0, 0–1}. So G1 ≅ G2.

Why these matter for a GCN
 1. Isomorphic graphs always get the same embedding. Renaming vertices only reorders
     the rows of H(l), and the sum h_G ignores order. So G1 ≅ G2 ⇒ h_G1 = h_G2, distance D
     = 0.
 2. The converse fails: GCN is not injective on graphs. Mean-style aggregation merges
    different neighbourhoods. A 6-cycle C6 and two separate triangles 2·C3 are not
     isomorphic, yet every vertex in both has degree 2, so both give the same h_G. This is
     the limit of the 1-WL (Weisfeiler–Lehman) test.
 3. Reading the result. D > 0 proves the graphs are not isomorphic. D = 0 only says
     "isomorphism candidate". No polynomial-time algorithm is known for exact graph
     isomorphism, so the GCN gives a fast filter.
 4. Surjectivity is not needed. ReLU outputs are never negative, so the map onto R^F is
     not onto. For comparing graphs only injectivity matters.

Phase 2: Mathematical concepts
Seven equations take a graph's adjacency matrix to one embedding vector h_G, and
compare two graphs by the distance between their vectors. Every equation is worked out
below for G1 (edges 0–1, 0–2, 1–2, 2–3; N = 4).

Eq.1: self-loops. Each vertex keeps its own features while aggregating.

  \tilde{A}^{N \times N} = A^{N \times N} + I_N


Eq.2: degree vector with self-loops. Multiply Ã by the all-ones column 1_N.

  \tilde{d}^{N \times 1} = \tilde{A}^{N \times N} \times \mathbf{1}^{N \times
  1}, \qquad \tilde{d}_i = \sum_{j=1}^{N} \tilde{A}_{ij}


G1: d̃ = [3, 3, 4, 2].

Eq.3: symmetric normalization. Divides each entry by the square root of both end
degrees, so high-degree vertices do not dominate.

  \hat{A} = \tilde{D}^{-1/2} \, \tilde{A} \, \tilde{D}^{-1/2}, \qquad
  \hat{A}_{ij} = \frac{\tilde{A}_{ij}}{\sqrt{\tilde{d}_i \, \tilde{d}_j}}

          // Eq.1 : A~ = A + I
          static double[][] addSelfLoops(double[][] A)
          {
                  int N = A.length;
                  double[][] At = new double[N][N];
                  for (int i = 0; i < N; i++)
                          for (int j = 0; j < N; j++)
                                 At[i][j] = A[i][j] + (i == j ? 1 : 0);
                  return At;
          }

          // Eq.2 : d~ = A~ x 1                     (row sums)

          static double[] degree(double[][] M)
          {
                  int N = M.length;
                  double[] d = new double[N];
                  for (int i = 0; i < N; i++)
                      for (int j = 0; j < N; j++)
                                 d[i] += M[i][j];
                  return d;
          }


          // Eq.3 : A^[i][j] = A~[i][j] / sqrt(d~_i * d~_j)
          static double[][] normalize(double[][] At, double[] dt)
          {
                  int N = At.length;
                  double[][] Ah = new double[N][N];
                  for (int i = 0; i < N; i++)
                          for (int j = 0; j < N; j++)
                          Ah[i][j] = At[i][j] / Math.sqrt(dt[i] * dt[j]);
                  return Ah;
          }


          // Eq.4 : H(0) row i = [ 1 , deg(v_i) ]
          static double[][] initialFeatures(double[][] A)
          {
                  double[] d = degree(A);
                  double[][] H = new double[d.length][2];
                  for (int i = 0; i < d.length; i++) { H[i][0] = 1; H[i][1] = d[i]; }
                  return H;
          }


          // Eq.5 : H(l+1) = ReLU( A^ x H(l) x W )
          static double[][] layer(double[][] Ah, double[][] H, double[][] W)
          {
                  int N = H.length, f = H[0].length, g = W[0].length;
                  double[][] HW = new double[N][g];
                  for (int i = 0; i < N; i++)
                      for (int k = 0; k < f; k++)
                                 for (int j = 0; j < g; j++)
                                     HW[i][j] += H[i][k] * W[k][j];
                  double[][] Hn = new double[N][g];
                  for (int i = 0; i < N; i++)
                          for (int k = 0; k < N; k++)
                              if (Ah[i][k] != 0)
                                  for (int j = 0; j < g; j++)
                                  Hn[i][j] += Ah[i][k] * HW[k][j];
                  for (int i = 0; i < N; i++)

                      for (int j = 0; j < g; j++)
                          Hn[i][j] = Math.max(0, Hn[i][j]);
                  return Hn;
          }


          // Eq.6 : h_G = sum over i of H(L)[i]
          static double[] readout(double[][] H)
          {
                  double[] h = new double[H[0].length];
                  for (double[] row : H)
                          for (int j = 0; j < row.length; j++)
                              h[j] += row[j];
                  return h;
          }


          // Eq.7 : D(G1, G2) = || h_G1 - h_G2 ||
          static double distance(double[] h1, double[] h2)
          {
                  double s = 0;
                  for (int j = 0; j < h1.length; j++) s += (h1[j] - h2[j]) * (h1[j] -
  h2[j]);
                  return Math.sqrt(s);
          }


          // full pipeline: Eq.1 -> Eq.6
          static double[] embed(String name, double[][] A, double[][] W, int L,
  boolean show)
      {
                  double[][] At = addSelfLoops(A);
                  double[] dt = degree(At);
                  double[][] Ah = normalize(At, dt);
                  double[][] H = initialFeatures(A);
                  for (int l = 1; l <= L; l++)
                  {
                          H = layer(Ah, H, W);
                          if (show) { System.out.println("[Eq.5] " + name + " H(" + l +
  "):"); print(H); }
          }
                  double[] h = readout(H);
                  System.out.printf("[Eq.6] h_%s = [%.4f, %.4f]%n", name, h[0], h[1]);
                  return h;
          }

Algorithm
The same steps as procedures, one per equation, in the notation of the class notes.

  procedure AddSelfLoops(A, N)                                             // Eq.1
  // A[1:N][1:N] adjacency matrix
  [
        for (i ← 1 … N)
        [ for (j ← 1 … N)
              [     if (i == j) Ã[i][j] ← A[i][j] + 1;
                    else        Ã[i][j] ← A[i][j];
           ] end for
        ] end for
     return Ã;
  ] end procedure


  procedure Degree(M, N)                                                   // Eq.2
  [
        for (i ← 1 … N)
        [ d[i] ← 0;
           for (j ← 1 … N) [ d[i] ← d[i] + M[i][j]; ] end for
        ] end for
        return d;
  ] end procedure

  procedure Normalize(Ã, d̃
                          , N)                                     // Eq.3
  [
        for (i ← 1 … N)
        [ for (j ← 1 … N)
           [ Â[i][j] ← Ã[i][j] / sqrt(d̃
                                       [i] × d̃
                                              [j]);               ] end for
        ] end for
        return Â;
  ] end procedure


  procedure InitialFeatures(A, N)                                  // Eq.4
  [
     Call: d ← Degree(A, N);
        for (i ← 1 … N) [ H[i][1] ← 1;              H[i][2] ← d[i]; ] end for
        return H;
  ] end procedure

  procedure Layer(Â, H, W, N, f, g)                                // Eq.5
  // H[1:N][1:f], W[1:f][1:g]
  [
        HW ← ∅; Hn ← ∅;                                            // nullify
        for (i ← 1 … N)                                            // transform: HW = H × W
        [     for (k ← 1 … f)
              [ for (j ← 1 … g) [ HW[i][j] ← HW[i][j] + H[i][k] × W[k][j]; ] end for
              ] end for
        ] end for
        for (i ← 1 … N)                                            // aggregate: Hn = Â × HW
        [     for (k ← 1 … N)
              [ if (Â[i][k] != 0)
                    [     for (j ← 1 … g) [ Hn[i][j] ← Hn[i][j] + Â[i][k] × HW[k][j]; ] end
  for
                    ]
           ] end for
        ] end for
        for (i ← 1 … N)                                // activate: ReLU
        [ for (j ← 1 … g) [ Hn[i][j] ← max(0, Hn[i][j]); ] end for
     ] end for
     return Hn;
  ] end procedure


  procedure Readout(H, N, g)                                       // Eq.6
  [
        h ← ∅;
        for (i ← 1 … N)
        [ for (j ← 1 … g) [ h[j] ← h[j] + H[i][j]; ] end for
        ] end for
        return h;

  procedure Compare(A1, A2, W, L, Δ)                                              // Eq.7, using Eq.1 … Eq.6
  [
        for (each graph G ∈ {A1, A2})
        [ Call: Ã ← AddSelfLoops(A);                            Call: d̃← Degree(Ã);
              Call: Â ← Normalize(Ã, d̃
                                      );                         Call: H ← InitialFeatures(A);
              for (l ← 1 … L) [ Call: H ← Layer(Â, H, W); ] end for
              Call: h_G ← Readout(H);
        ] end for
        D ← sqrt( Σ_j (h_G1[j] − h_G2[j])² );
        if (D <= Δ) return "isomorphism candidate";
        else return "NOT isomorphic";
  ] end procedure




Analysis
Comparing two graphs costs O(L·N²) time and O(N²) space with the dense matrices used
in the code. Here N = number of vertices, m = number of edges, L = number of layers, f and
g = feature widths in and out of a layer (f = g = 2 here).


  Procedure                     Equation            Time T(n)                    Space S(n)

  AddSelfLoops                  Eq.1                O(N²)                        O(N²)

  Degree                        Eq.2                O(N²)                        O(N)

  Normalize                     Eq.3                O(N²)                        O(N²)

  InitialFeatures               Eq.4                O(N²) (calls Degree)         O(N·f)

  Layer (one call)              Eq.5                O(N·f·g + N² + (N + 2m)·g)   O(N·g)

  Readout                       Eq.6                O(N·g)                       O(g)

  Distance                      Eq.7                O(g)                         O(1)

  Layer: transform H × W                                 -> N·f·g
                scan every Â[i][k]                        -> N²
                multiply the non-zeros                     -> (N + 2m)·g     (Â has N self-loops + 2
  per edge)
                ReLU                                       -> N·g

  One graph = Eq.1 + Eq.2 + Eq.3 + Eq.4 + L × Eq.5 + Eq.6
                      = O(N²) + O(L · (N² + N·f·g))
            = O(L · N²)                                             -> f, g constant
  Two graphs + Eq.7 = 2 × O(L · N²) + O(g)


  E[T(n)] : O(L · N²)
  E[S(n)] : O(N² + N·g)                             -> Ã and Â (N × N) + feature rows H


With adjacency lists instead of N × N matrices, only the non-zeros are stored and visited:

  E[T(n)] : O(L · (N + m) · g)                            -> linear in the size of the graph
  E[S(n)] : O(N + m + N·g)


For sparse graphs (m much smaller than N²) this is the version to use; the dense one is
kept in the code because it is easier to write out and to check by hand.
